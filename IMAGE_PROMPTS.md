# Making card art

Every tool already has all eight moods in [`images/`](images/). Claude and
ChatGPT's main moods are hand-made; the rest are generated by
`tools/make_tool_art.py`, which takes the Claude mascot art, swaps the laptop
logo for a neon glyph of the tool, and recolours the *cooking* picture to the
tool's colour.

To replace any picture with hand-made art, generate it with the prompts below
and save it into `images/` with the same name (`.jpg` or `.png`, square; 512 px
is plenty because Discord shows it at about 100 px). The card picks it up within
a few hours, or right away after restarting the service.

## Where pictures show

- **Big picture** (rounded square, ~100 px): `<tool>_<mood>`, where tool is
  `claude chatgpt gemini grok muse copilot opencode aider cursor windsurf kiro
  vscode` and mood is one of the eight below. If a mood is missing, *crew*
  and *success* fall back to *cooking*, *push* to *success*, and *failed* to
  *waiting*. *sim* falls back to `claude_sim`, which has no logo in it.
- **Small badge** (circle, ~30 px, bottom-right of the big picture): changes
  with the rotating line. The names are listed in [`images/README.md`](images/README.md).
  None of these exist yet; the card simply leaves the badge off.

## Style (paste this first in every ChatGPT message)

```
Square 1024x1024 illustration in a neon "AI coding mascot" style: a cute
rounded robot with a glossy dark visor face showing simple glowing eyes,
headphones and a ball antenna, sitting at a dark laptop. Dark room, glowing
holographic code panels in the background, strong neon rim light, rounded-square
frame with a soft glow, black outside the frame. No text other than code-like
squiggles on the screens.
```

## The eight moods

```
cooking : happy closed-eye smile, typing fast, sparks and speed lines, full
          brightness in the tool's colour
waiting : sleepy half-closed eyes, chin on an hourglass, amber light, floating
          "?" and a "..." speech bubble
success : cheering with both fists up, big green check mark, "all tests passed"
          panels, green light
failed  : frustrated, hands on head, red light, "build failed / tests failed"
          panels, crumpled paper, knocked-over mug
idle    : asleep with "zzz", monochrome grey, dim
crew    : three robots side by side at laptops in a command center, a glowing
          globe between them, git / terminal / package / check icons below
push    : cheering with one fist up, a rocket launching from the screen with
          files trailing behind it, "pushed to origin/main", purple light
sim     : pointing at a holographic 3D terrain map with drones and waypoints,
          "simulation running" checklist, orange control-room light
```

Then name the tool, its colour, and the symbol on its laptop, e.g.:

```
Tool: Cursor. Colour: silver-white with electric-blue edges. Laptop symbol: an
arrow pointer. Make the "cooking", "success" and "failed" moods.
```

Laptop symbols used by the generated set: Claude asterisk-starburst, ChatGPT
six-loop rosette, Gemini four-point sparkle, Grok ring with a diagonal streak,
Muse infinity loop, Copilot goggles, OpenCode `{ }`, Aider two speech bubbles,
Cursor arrow pointer, Windsurf sail over a wave, Kiro ghost, VS Code `</>`.
