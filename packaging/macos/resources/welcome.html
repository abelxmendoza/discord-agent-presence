Agent Presence __VERSION__

Discord Rich Presence for AI coding tools. Your Discord profile shows when you're working in Claude, Codex, Gemini, Copilot, Cursor, Windsurf, Kiro, VS Code and more, with your projects, how many agents are running and what they're doing right now.

This installer will:

  • install Agent Presence in /Library/Application Support/Agent Presence
  • add the agent-presence command
  • start it now and at every login

No code ever leaves your Mac. Only the card text goes to your local Discord app.
