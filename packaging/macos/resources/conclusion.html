You're live on Discord 🎉

Agent Presence is running and will start every time you log in.

  1. Open the Discord desktop app and start one of your AI tools. Your profile card appears within a few seconds.
  2. To show which project is open in Cursor or VS Code, allow Python under System Settings → Privacy & Security → Accessibility.
  3. In Terminal, agent-presence doctor checks everything and agent-presence detect previews your cards.

To remove it later, run
sudo "/Library/Application Support/Agent Presence/uninstall.sh"

If anything went wrong, the install log is at /tmp/agent-presence-install.log.
