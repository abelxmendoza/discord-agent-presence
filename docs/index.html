Install

Up and running in about a minute

No Discord developer setup needed. The cards use shared Discord apps that ship with the tool.

Download the installer

One file for Apple silicon and Intel Macs, macOS 11 or later.

Download for Mac (.dmg)

Open it and double-click Agent Presence

Click Install. It sets everything up and starts by itself at every login. No terminal needed.

First time only: macOS may say it can't check the app for malware, because it isn't from the App Store. Click Done, open System Settings → Privacy & Security, scroll down and click Open Anyway next to Agent Presence. The app is open source, so you can read exactly what it does.

Optional: allow window titles

Click Allow Window Titles… at the end so projects open in Cursor or VS Code show on your card too. Agents from Claude, Codex and the rest work without it.

Open Discord

Start any AI tool and your card shows up on your profile within a few seconds.

Update, uninstall, or use the terminal instead

To update, download the new .dmg and open the app again: it offers Update. Open it any time to Restart or Uninstall.

Prefer the terminal? This does the same thing:

curl -fsSL https://raw.githubusercontent.com/abelxmendoza/discord-agent-presence/main/install.sh | bash

Then agent-presence doctor checks Discord and lists the apps it found, and agent-presence detect previews your cards.

Run the installer in PowerShell

Needs Python 3.9+ from python.org (tick "Add to PATH"). It downloads the tool, adds the agent-presence command and starts it on login.

irm https://raw.githubusercontent.com/abelxmendoza/discord-agent-presence/main/install.ps1 | iex

Check everything's found

It confirms Discord is running and lists which of your AI apps it detected.

agent-presence doctor

Preview your cards

It prints exactly what Discord will show, line by line. Then open your profile and look.

agent-presence detect

README & website

Show it beyond Discord

Put a live card on your GitHub profile and a full status panel on your portfolio, so people and recruiters see what you're building right now. It shows more than Discord has room for: every agent and what it's doing, your projects with branches and CI, which computers you're on, and today's totals.

Turn it on

Uses your GitHub login from the GitHub CLI (or a token). --readme adds the card to your profile README for you, after asking.

agent-presence web setup --readme

Or paste it yourself

Type your profile repo to get the snippets.

Your computer updates the card every couple of minutes while you work and marks you offline when you log off. It publishes to a side branch of your repo, one commit that's replaced each time, so it never touches your contribution graph.

FAQ

      
Questions

    

    
What does it share? Is any of my code sent anywhere?
      
No code ever leaves your machine. Only the card text goes to your local Discord app: project names, branch names, file names and commit counts. Anyone who can see your profile can see these. Hide a repo with hide_projects, or turn off any line (show_files, show_git, …) in ~/.config/ai-presence/config.json. Commit messages and full paths are never shown.

    
How does it know what my agents are doing?
      
It reads the session logs Claude Code and Codex already write on your machine, and looks at the latest action in each one. For Grok it checks the running CLI process. Window titles show which project is open in Cursor or VS Code.

    
Discord already shows VS Code for me. Won't I get two cards?
      
Turn off Discord's own detection for Visual Studio Code under Settings → Registered Games, and the Agent Presence card, with projects and agents, takes its place.

    
Can I rename the cards or use my own icons?
      
Yes. Create your own application in the Discord Developer Portal and put its ID under client_ids. Point image_base_url at your own art for custom pictures.

    
Does it work on Mac and Windows?
      
Yes. It runs on Linux (X11), macOS and Windows, and it's tested on all three. On a Mac, download the .dmg and double-click the app; it has a button that walks you through allowing window titles (Accessibility) for editor projects. agent-presence doctor tells you if that's missing. Linux on Wayland can't read window titles yet, but agents and session logs still work.

    
I code on more than one computer. What happens?
      
Install it on each one and link them with agent-presence link. They share one card that follows whichever computer you're using, counts the agents running on all of them, and shows which machines are in use, like 🖥 2 machines: 💻 MacBook Pro (3) · 🖥 Aurora R16 (2). Each card also names the computer and OS. Hostnames are never shown.

    
Can I add another tool, like Windsurf, Zed or Aider?
      
Yes. Each tool is a few lines saying how to find its process, window and session logs. Open a pull request on GitHub.
