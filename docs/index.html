Install

Up and running in about a minute

No Discord developer setup needed. The cards use shared Discord apps that ship with the tool.

Run the installer

It clones the tool, adds the agent-presence command and starts it on login.

curl -fsSL https://raw.githubusercontent.com/abelxmendoza/discord-agent-presence/main/install.sh | bash

Check everything's found

It confirms Discord is running and lists which of your AI apps it detected.

agent-presence doctor

Preview your cards

It prints exactly what Discord will show, line by line. Then open your profile and look.

agent-presence detect
FAQ

Questions

What does it share? Is any of my code sent anywhere?

No code ever leaves your machine. Only the card text goes to your local Discord app: project names, branch names, file names and commit counts. Anyone who can see your profile can see these. Hide a repo with hide_projects, or turn off any line (show_files, show_git, …) in ~/.config/ai-presence/config.json. Commit messages and full paths are never shown.

How does it know what my agents are doing?

It reads the session logs Claude Code and Codex already write on your machine, and looks at the latest action in each one. For Grok it checks the running CLI process. Window titles show which project is open in Cursor or VS Code.

Discord already shows VS Code for me. Won't I get two cards?

Turn off Discord's own detection for Visual Studio Code under Settings → Registered Games, and the Agent Presence card, with projects and agents, takes its place.

Can I rename the cards or use my own icons?

Yes. Create your own application in the Discord Developer Portal and put its ID under client_ids. Point image_base_url at your own art for custom pictures.

macOS, Windows, Wayland?

Linux on X11 for now. The Discord side works on every platform; detecting the focused window is the platform-specific part. Contributions are welcome.

Can I add another tool, like Windsurf, Zed or Aider?

Yes. Each tool is a few lines saying how to find its process, window and session logs. Open a pull request on GitHub.
